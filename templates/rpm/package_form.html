How it works
  1. The repository is cloned at the specified branch.
  2. The SPEC file is found at the path you provide.
  3. An SRPM is built first using Mock, then binary RPMs are built from it.
  4. Built RPMs are stored in the distribution's local repo and createrepo is run so they can be used as build dependencies for future packages.
  5. One build record is created per selected distribution.
