Using the token with curl

Send the token in an Authorization header. Replace the example values as needed. 

export FLATMAN_URL={{ request.scheme }}://{{ request.get_host }}
export FLATMAN_TOKEN=<your token>

# List repositories
curl -H "Authorization: Token $FLATMAN_TOKEN" \
     "$FLATMAN_URL/api/repositories/"

# Create a repository
curl -X POST \
     -H "Authorization: Token $FLATMAN_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"name": "stable", "collection_id": "org.example.Stable"}' \
     "$FLATMAN_URL/api/repositories/"

# Start a build for package 1
curl -X POST \
     -H "Authorization: Token $FLATMAN_TOKEN" \
     "$FLATMAN_URL/api/packages/1/start/"

The same token works with the mrmeee.flatman Ansible collection through the FLATMAN_API_TOKEN environment variable.
