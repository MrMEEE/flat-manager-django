BuildStream 1

BST 1 and BST 2 use incompatible project.conf formats. BST 2 is available as bst in the primary virtualenv. BST 1 requires Python ≤ 3.11 — use the helper script to create its venv: 

# local dev (any path)
./setup-bst1-venv.sh ./venv-bst1

# system-wide (RPM default)
sudo ./setup-bst1-venv.sh /opt/flat-manager/bst1-venv

On Ubuntu the script installs python3.11 via apt automatically if needed (available in universe on 22.04 / 24.04 without a PPA).
