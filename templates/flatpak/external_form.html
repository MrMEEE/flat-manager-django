How to find the ref

The OSTree ref string has the form:

type/name/arch/branch

Examples:

  • runtime/org.kde.Platform/x86_64/5.15
  • runtime/org.freedesktop.Platform/x86_64/23.08
  • app/org.gnome.Builder/x86_64/stable

Run flatpak remote-ls <remote> to list available refs from a configured remote.
