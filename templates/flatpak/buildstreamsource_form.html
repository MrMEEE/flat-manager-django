About BuildStream Sources

A BuildStream source represents a project that produces multiple Flatpak refs (runtimes, SDKs, extensions) in a single build. Unlike a regular Package, there is no single application ID.

Pipeline:
git clone → bst build → bst artifact checkout → flatpak build-commit-from

The element's artifact is expected to be a complete OSTree flatpak repo (like flatpak-release-repo.bst in freedesktop-sdk).
