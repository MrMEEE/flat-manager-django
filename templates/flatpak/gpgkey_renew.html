About Key Renewal

Key renewal extends the expiry date embedded in the existing key material — the key ID and fingerprint remain unchanged.

  • The public key is re-exported with the new expiry
  • Repository .gpg files are updated automatically
  • Clients must re-fetch the public key to verify future downloads
  • The new expiry is measured from today
After renewal, inform users of repositories that use this key to re-add the remote so they pick up the updated public key.
